# YottaFlex Industrial Safety Monitoring

Deterministic synthetic industrial safety dataset, analytics layer, validation
harness and **SAFEGUARD** — a Streamlit-based industrial safety monitoring
dashboard.

> **Synthetic data only.** Every alarm, incident, acknowledgement and corrective
> action is generated by a seeded script.  This project makes no claim of
> ISA-18.2 or IEC 61511 compliance and produces no operational KPIs for real
> industry.

---

## Quickstart

```bash
python -m pip install -r requirements.txt        # runtime
python -m pip install -r requirements-dev.txt  # runtime + pytest

python src/pipeline.py --with-analysis         # generate + analyze + validate
python -m pytest tests -q                      # test suite
streamlit run dashboard/app.py                 # dashboard -> http://localhost:8501
```

The dashboard can also be pointed at a different dataset directory:

```bash
python src/pipeline.py --data-dir /custom/data
```

```
             detection, validators, exports, dashboard smoke tests)

```

## What the project does

1. **Generate** a deterministic, safety-oriented alarm dataset
   (seed `20261022`, 50,000 alarm activations over 30 days, 4 plants, 60
   machines, 200 alarm definitions).
2. **Analyze** alarm acknowledgement compliance using **activation-denominated**
   rates (all alarms ÷ all activations), with median / p95 response times,
   per-priority breakdowns, routine SLA breaches and genuine anomalies.
3. **Detect** five injected safety anomalies plus three negative controls with a
   scenario harness (`data/scenarios/`).
4. **Validate** referential integrity, schema contracts, lifecycle consistency
   and detector behaviour (94 baseline checks, 40 edge-case checks).
5. **Serve** the results through the redesigned SAFEGUARD Streamlit dashboard with
   global filters and per-page analytics.
